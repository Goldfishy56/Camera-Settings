One-time setup

  1. Open aistudio.google.com/apikey and sign in with Google.
  2. Tap Create API key and copy it. It's free, no card needed.
  3. Paste it here. It stays on this phone only.

Load a reel

  1. In Instagram, tap ⋯ on the reel → Download (or screen-record it).
  2. Choose that video below and tap Get settings.
